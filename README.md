# Finance Data Bridge - Excel Add-in

Excel 웹 추가기능을 위한 정적 파일 저장소입니다.

## 🚀 설치 방법

Excel 추가기능 설치를 위해서는 별도로 제공되는 `manifest.xml` 파일이 필요합니다.

### Excel에서 추가기능 설치
1. Excel Online 열기
2. **삽입** → **추가기능** → **내 추가기능**
3. **사용자 지정 추가기능 업로드** 클릭
4. 제공받은 `manifest.xml` 파일 선택
5. **업로드** 클릭

## 📋 기능

- **계정 업로드**: Excel 데이터를 API 서버로 업로드
- **DSL 확인**: 재무 수식 DSL 구문 검증

## 🤖 자동 배포

이 저장소는 메인 프로젝트에서 자동으로 배포됩니다.
